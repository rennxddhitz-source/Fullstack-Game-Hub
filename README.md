# Fullstack IO Game Starter (.IO Style)

Game multiplayer real-time bergaya `.io` menggunakan **Node.js**, **Express**, **Socket.io**, dan **HTML5 Canvas**.

## Cara Menjalankan Secara Lokal:
1. Pastikan Node.js sudah terinstal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan server:
   ```bash
   npm start
   ```
4. Buka browser di `http://localhost:3000`. Buka beberapa tab untuk mencoba multiplayer secara real-time!
